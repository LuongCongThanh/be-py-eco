Functions & Unpacking — Cheat Sheet

Định nghĩa hàm

def greet(name):
    return f"hello, {name}!"

greet("world")   # "hello, world!"

def thay cho từ khóa khai báo hàm; không cần khai báo kiểu trả về hay kiểu tham số (dù có thể thêm gợi ý kiểu — xem bên dưới).

Giá trị mặc định cho tham số

def greet(name, greeting="hello"):
    return f"{greeting}, {name}!"

greet("world")            # "hello, world!"
greet("world", "hi")      # "hi, world!"
greet("world", greeting="yo")   # "yo, world!" — gọi bằng tên tham số

Trả về nhiều giá trị = trả về một tuple

def min_max(numbers):
    return min(numbers), max(numbers)

lo, hi = min_max([3, 1, 4, 1, 5])   # lo = 1, hi = 5

Python không có "multiple return values" thật sự — return a, b gói a và b vào một tuple (a, b). Vế trái lo, hi = ... "tách" (unpack) tuple đó ra hai biến.

Unpacking tổng quát

point = (3, 4)
x, y = point            # x = 3, y = 4

first, *rest = [1, 2, 3, 4]   # first = 1, rest = [2, 3, 4]

Gợi ý kiểu (type hints) — không bắt buộc, chỉ để tài liệu hóa

def greet(name: str, greeting: str = "hello") -> str:
    return f"{greeting}, {name}!"

Python không kiểm tra kiểu lúc chạy vì những hint này — chúng chỉ giúp người đọc và công cụ như mypy (dùng trong be-py-eco) bắt lỗi sớm.
