manage.py & urls.py — Cheat Sheet (theo be-py-eco)

if __name__ == "__main__":

if __name__ == "__main__":
    main()

__name__ là biến đặc biệt Python gán tự động cho mỗi module: bằng "__main__" khi file được chạy trực tiếp (python manage.py), khác đi khi file được import từ nơi khác. Idiom này nghĩa là "chỉ chạy main() khi file này là file khởi động, không chạy khi bị import".

manage.py làm 3 việc

sys.path.insert(0, str(SRC_DIR))
os.environ.setdefault("DJANGO_SETTINGS_MODULE", "config.settings.local")
execute_from_command_line(sys.argv)
  1. Thêm src/ vào đường dẫn tìm module (để import config... hoạt động).
  2. setdefault: đặt DJANGO_SETTINGS_MODULE nếu nó chưa được set — khác với gán trực tiếp (=), setdefault không ghi đè nếu bạn đã set biến môi trường từ trước (như trong how-to-run.md).
  3. Chuyển toàn bộ tham số dòng lệnh (sys.argv) cho Django xử lý — đây là lý do manage.py migrate, manage.py runserver đều gọi qua cùng 1 file.

urls.py: bản đồ URL → view

# cu phap tong quat
from django.urls import path
urlpatterns = [
    path("health/", health_check_view),
    path("api/v1/orders/", order_list_view),
]

Mỗi path(...) nối một URL với một hàm/class xử lý request (gọi là view). Trong be-py-eco, src/config/urls.py hiện đang rỗng (urlpatterns = []) — dự án còn ở Slice 0, chưa có route nào được thêm; các route /api/v1/... và /health/* sẽ vào ở Slice 1.
