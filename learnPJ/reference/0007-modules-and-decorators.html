Module & Decorator cơ bản — Cheat Sheet

Import module

import math
math.sqrt(16)          # 4.0

from math import sqrt
sqrt(16)                # 4.0

from math import sqrt as square_root
square_root(16)          # 4.0

Mỗi file .py là một module. import tên module để dùng qua dấu chấm, hoặc from ... import ... để lấy thẳng tên ra dùng trực tiếp.

Import trong be-py-eco

# src/modules/foo/models.py
from django.db import models
from common.db import BaseModel

Cấu trúc thư mục (src/common/db.py) ánh xạ trực tiếp vào đường dẫn import (from common.db import ...) — xem README.md §Project layout.

Decorator: hàm bọc quanh hàm khác

def log_call(func):
    def wrapper(*args, **kwargs):
        print(f"goi {func.__name__}")
        return func(*args, **kwargs)
    return wrapper

@log_call
def greet(name):
    return f"hello, {name}"

greet("Lan")
# in ra: "goi greet"
# tra ve: "hello, Lan"

@log_call phía trên def greet tương đương viết greet = log_call(greet). Decorator "bọc" hàm gốc bằng một hàm khác, thêm hành vi mà không sửa code bên trong hàm gốc.

Decorator bạn sẽ gặp thường xuyên trong Django/DRF

@api_view(["GET"])
def my_view(request):
    ...

@login_required
def my_view(request):
    ...

Đây chính là lý do cần hiểu decorator: rất nhiều code Django/DRF dùng @... phía trên function/method để thêm hành vi (kiểm tra quyền, giới hạn HTTP method, cache, ...).
