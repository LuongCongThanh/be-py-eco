Exception Handling & Context Manager — Cheat Sheet

try / except

try:
    result = 10 / 0
except ZeroDivisionError:
    print("khong the chia cho 0")
except (ValueError, TypeError) as e:
    print(f"loi khac: {e}")
else:
    print("chi chay neu KHONG co loi")
finally:
    print("luon chay, co loi hay khong")

except phải chỉ rõ loại exception (hoặc tuple các loại) — không có khối catch "bắt mọi thứ" mặc định như một số ngôn ngữ. else và finally đều tùy chọn.

Tự ném lỗi

def divide(a, b):
    if b == 0:
        raise ValueError("b khong duoc bang 0")
    return a / b

Context manager: with thay cho try/finally đóng resource

with open("file.txt") as f:
    content = f.read()
# file tu dong duoc dong khi ra khoi block "with",
# ke ca khi co loi xay ra ben trong

Tương đương thủ công (không nên viết tay khi có with):

f = open("file.txt")
try:
    content = f.read()
finally:
    f.close()

Vì sao quan trọng với be-py-eco

Kết nối database, transaction, file, lock — mọi resource cần "dọn dẹp chắc chắn" đều nên dùng with. Ví dụ Django's transaction.atomic() chính là một context manager.
