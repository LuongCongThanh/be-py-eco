DRF Serializer & View — Cheat Sheet

Serializer: chuyển đổi 2 chiều model ↔ dict/JSON

from rest_framework import serializers

class BookSerializer(serializers.ModelSerializer):
    class Meta:
        model = Book
        fields = ["id", "title", "author", "available"]
# Model -> JSON (serialize)
serializer = BookSerializer(book_instance)
serializer.data   # {"id": ..., "title": "...", "author": "...", "available": true}

# JSON -> Model (deserialize + validate)
serializer = BookSerializer(data=request.data)
serializer.is_valid()        # chay validation, tra ve True/False
serializer.validated_data    # dict da duoc lam sach
serializer.save()             # tao/cap nhat model trong DB

APIView: class xử lý request theo HTTP method

from rest_framework.views import APIView
from rest_framework.response import Response

class BookListView(APIView):
    def get(self, request):
        books = Book.objects.all()
        serializer = BookSerializer(books, many=True)
        return Response(serializer.data)

    def post(self, request):
        serializer = BookSerializer(data=request.data)
        if serializer.is_valid():
            serializer.save()
            return Response(serializer.data, status=201)
        return Response(serializer.errors, status=400)

Mỗi HTTP method (GET, POST, PUT, DELETE) ứng với một method cùng tên (viết thường) trong class. Đây là lý do bài 4 (class, method) và bài 6 (raise/except — ở đây thay bằng kiểm tra is_valid() tường minh, DRF khuyến khích check lỗi thay vì except) đều cần thiết.

Đăng ký route trong urls.py

from django.urls import path
urlpatterns = [
    path("api/v1/books/", BookListView.as_view()),
]

.as_view() chuyển 1 class thành 1 function Django hiểu được — nối lại với urls.py đã học ở bài 10.
