Cú pháp cơ bản Python — Cheat Sheet

Block dựa trên thụt lề, không dùng dấu ngoặc

if x > 0:
    print("positive")
else:
    print("non-positive")

Dấu hai chấm : mở một block; thụt lề nhất quán (4 spaces, theo quy ước PEP 8) xác định cái gì nằm bên trong block đó. Không có dấu ngoặc nhọn, không có từ khóa end.

Biến: không khai báo kiểu

x = 5        # int
x = "five"   # giờ là str — cùng tên biến, không lỗi

Một tên biến có thể được gán lại cho bất kỳ kiểu nào. Giá trị mới có kiểu (được kiểm tra lúc chạy); biến thì không.

f-string (chèn giá trị vào chuỗi)

name = "world"
print(f"hello, {name}!")   # hello, world!

Truthiness

0, 0.0, "", [], {}, và None đều là falsy (bị coi là sai). Mọi thứ khác là truthy. if my_list: nghĩa là "nếu list này không rỗng".
