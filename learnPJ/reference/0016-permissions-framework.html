Permission framework — Cheat Sheet

Lớp 1 (view): lọc loại actor

class IsStaff(BasePermission):
    def has_permission(self, request, view):
        return isinstance(request.user, Staff)

Chỉ trả lời "đây có phải Staff không" — không biết gì về role/quyền cụ thể.

Lớp 2 (service): ROLE_PERMISSIONS + check_policy

ROLE_PERMISSIONS = {
    "master_admin": {"accounts.create_staff", "accounts.disable_customer"},
    "store_manager": {"accounts.disable_customer"},
    "order_staff": set(),
}

def has_permission(role, codename):
    return codename in ROLE_PERMISSIONS.get(role, set())

def check_policy(*, role, codename, obj=None, object_check=None):
    if not has_permission(role, codename):
        return False
    return object_check(obj) if object_check is not None else True

object_check: callback tùy chọn để kiểm tra thêm với một object cụ thể sau khi đã có quyền thô theo role.

Gọi từ service, raise lỗi thay vì trả bool

def require_permission(*, role, codename, obj=None, object_check=None):
    if not check_policy(role=role, codename=codename, obj=obj, object_check=object_check):
        raise PermissionDeniedError(f"Role '{role}' lacks permission '{codename}'.")

# hoac check truc tiep trong service, tu raise loi rieng cua module:
if not check_policy(role=actor.role, codename=CREATE_STAFF_CODENAME):
    raise InsufficientPermissionError

Luôn gọi từ service — không gọi từ view — để quy tắc phân quyền tập trung một nơi.
