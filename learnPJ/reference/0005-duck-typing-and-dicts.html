Duck Typing & Dict/Set — Cheat Sheet

Duck typing: quan tâm hành vi, không quan tâm kiểu khai báo

def make_it_speak(animal):
    return animal.speak()   # không kiểm tra animal là kiểu gì

class Dog:
    def speak(self): return "woof"

class Duck:
    def speak(self): return "quack"

make_it_speak(Dog())    # "woof"
make_it_speak(Duck())   # "quack" — không cần Dog và Duck cùng kế thừa 1 interface

"If it walks like a duck and quacks like a duck, it's a duck" — hàm không quan tâm animal thuộc class nào, chỉ cần nó có method speak(). Không cần khai báo interface nào.

dict: các thao tác thường dùng

person = {"name": "Lan", "age": 25}

person["name"]              # "Lan"
person.get("job", "n/a")    # "n/a" — không lỗi nếu thiếu key
person["job"] = "engineer"  # thêm/sửa key

for key, value in person.items():
    print(key, value)

"age" in person              # True — kiểm tra key có tồn tại

Dict comprehension

squares = {x: x * x for x in range(5)}
# {0: 0, 1: 1, 2: 4, 3: 9, 4: 16}

set: tập hợp không trùng lặp

a = {1, 2, 3}
b = {2, 3, 4}

a | b   # {1, 2, 3, 4} — hợp (union)
a & b   # {2, 3}       — giao (intersection)
a - b   # {1}          — hiệu (difference)

Dùng set khi cần loại trùng lặp hoặc kiểm tra "phần tử này có trong tập không" cực nhanh — nhanh hơn nhiều so với kiểm tra trong list.
