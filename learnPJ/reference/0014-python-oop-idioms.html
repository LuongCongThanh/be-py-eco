Encapsulation: quy ước, không phải từ khóa private

class Account:
    def __init__(self, balance):
        self._balance = balance     # quy uoc: "internal", dung tu y truy cap
        self.__secret = "x"          # name-mangled, kho truy cap tu ben ngoai hon

Python không có private/public thật sự. 1 dấu gạch dưới đầu (_balance) là quy ước "đừng đụng vào từ bên ngoài" — vẫn truy cập được, chỉ là bất lịch sự. 2 dấu gạch dưới (__secret) kích hoạt "name mangling" (Python đổi tên thuộc tính thành _Account__secret), khó truy cập nhầm hơn nhưng vẫn không phải bảo mật thật.

@property: gọi method như thuộc tính

class Circle:
    def __init__(self, radius):
        self.radius = radius

    @property
    def area(self):
        return 3.14159 * self.radius ** 2

c = Circle(2)
c.area        # 12.566 — goi nhu thuoc tinh, KHONG phai c.area()

Dùng khi muốn 1 giá trị được tính toán, nhưng vẫn truy cập với cú pháp gọn như thuộc tính thường, không phải gọi hàm.

@classmethod và @staticmethod

class Book:
    def __init__(self, title):
        self.title = title

    @classmethod
    def from_string(cls, raw):        # nhan class (cls), khong nhan instance
        return cls(raw.strip().title())

    @staticmethod
    def is_valid_title(title):        # khong nhan self hay cls
        return len(title) > 0

Book.from_string("  chi pheo  ")   # Book(title="Chi Pheo")
Book.is_valid_title("")             # False

@classmethod: nhận cls (chính class) thay vì self — thường dùng làm "constructor phụ" (alternative constructor). @staticmethod: không nhận gì đặc biệt cả, chỉ là hàm thường được "nhóm" vào trong class vì liên quan logic.

Dunder methods khác ngoài __init__

class Book:
    def __init__(self, title):
        self.title = title

    def __str__(self):
        return f"Book: {self.title}"      # str(book) / print(book)

    def __eq__(self, other):
        return self.title == other.title   # book1 == book2

print(Book("A"))          # "Book: A"
Book("A") == Book("A")     # True

Không định nghĩa __eq__, == giữa 2 object sẽ so sánh theo identity (có phải cùng 1 object trong bộ nhớ không), giống is, chứ không so sánh nội dung.

Polymorphism trong Python thường qua duck typing (bài 5)

Nhiều ngôn ngữ dùng abstract class/interface để ép polymorphism. Python có abc module cho việc đó, nhưng phổ biến hơn trong code Python thực tế là dựa hẳn vào duck typing: không cần khai báo interface, chỉ cần object có đúng method cần dùng.
