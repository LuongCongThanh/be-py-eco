Vòng lặp & Comprehension — Cheat Sheet

for: lặp trực tiếp trên phần tử

fruits = ["apple", "banana", "cherry"]
for fruit in fruits:
    print(fruit)

for trong Python luôn là "for-each" — không có kiểu for (i = 0; i < n; i++).

range(): khi cần đếm số

for i in range(5):        # 0, 1, 2, 3, 4
    print(i)

for i in range(2, 10, 2): # 2, 4, 6, 8
    print(i)

enumerate(): cần cả chỉ số lẫn giá trị

for i, fruit in enumerate(fruits):
    print(i, fruit)   # 0 apple / 1 banana / 2 cherry

while: giống hầu hết ngôn ngữ khác

n = 5
while n > 0:
    print(n)
    n -= 1        # không có n--

List comprehension: xây list từ một vòng lặp, trong 1 dòng

squares = [x * x for x in range(5)]
# tương đương:
squares = []
for x in range(5):
    squares.append(x * x)

# có điều kiện lọc
evens = [x for x in range(10) if x % 2 == 0]

Cấu trúc: [biểu_thức for biến in iterable if điều_kiện]. Phần if là tùy chọn.

break / continue

Giống hầu hết ngôn ngữ: break thoát vòng lặp, continue bỏ qua phần còn lại của lần lặp hiện tại.
