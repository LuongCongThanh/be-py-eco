Django Settings — Cheat Sheet (theo be-py-eco)

Settings là một module Python bình thường

# src/config/settings/base.py
SECRET_KEY = env("SECRET_KEY")
DEBUG = env.bool("DEBUG", default=False)
DATABASES = {"default": env.db_url("DATABASE_URL")}

Không có DSL riêng — settings chỉ là biến toàn cục trong 1 file .py. Django import module này và đọc các biến ra.

DJANGO_SETTINGS_MODULE: đường dẫn dotted tới module đó

$env:DJANGO_SETTINGS_MODULE = "config.settings.local"

Chuỗi "config.settings.local" tương ứng file src/config/settings/local.py — dấu chấm thay cho dấu /, giống import config.settings.local.

Layering: local/test/production kế thừa base bằng import *

# src/config/settings/local.py
from .base import *   # lay toan bo bien tu base.py

DEBUG = True           # roi ghi de rieng 1 bien

from .base import * đưa toàn bộ biến trong base.py vào namespace của local.py, sau đó local.py chỉ ghi đè những gì khác biệt (ở đây chỉ DEBUG = True).

django-environ: đọc config từ .env, không hard-code

env("SECRET_KEY")              # bat buoc phai co trong .env, khong co -> loi
env.bool("DEBUG", default=False)   # co gia tri mac dinh neu thieu
env.db_url("DATABASE_URL")         # parse chuoi ket noi DB thanh dict

env(...) ở đây không phải cú pháp Python đặc biệt — nó là một object (env = environ.Env()) mà bạn gọi như một hàm nhờ dunder method __call__. Bạn chưa cần hiểu __call__ sâu — chỉ cần biết env(...) đọc 1 biến môi trường, khớp với file .env đã set ở how-to-run.md.
