Testing với pytest-django — Cheat Sheet (theo be-py-eco)

Test = một hàm bắt đầu bằng test_

# tests/common/test_ids.py
import uuid
from common.ids import uuid7

def test_uuid7_returns_valid_uuid():
    value = uuid7()
    assert isinstance(value, uuid.UUID)
    assert value.version == 7

Không cần class, không cần @Test annotation. pytest tự tìm mọi hàm tên test_* trong file test_*.py và chạy chúng. assert là từ khóa Python có sẵn — nếu biểu thức sau nó là False, test fail và pytest tự in ra giá trị thực tế để debug.

Đánh dấu test cần database: @pytest.mark.django_db

# tests/test_environment.py
import pytest
from django.db import connection

@pytest.mark.django_db
def test_database_connection_is_reachable():
    connection.ensure_connection()
    assert connection.is_usable()

Nhận ra @pytest.mark.django_db? Đây là decorator (bài 7) — báo cho pytest-django biết: test này cần một database test riêng. Không có decorator này, test chạm vào DB sẽ báo lỗi "database access not allowed".

Vì sao be-py-eco chạy test trên Postgres thật, không SQLite

pytest-django tự tạo một database test riêng (test_be_py_eco) trước khi chạy suite, và xóa đi sau khi xong — mỗi test được cô lập trong 1 transaction bị rollback ở cuối, nên test không ảnh hưởng lẫn nhau. Xem guild.md §10.5 để biết lý do chọn Postgres thật thay vì SQLite (tránh khác biệt hành vi giữa 2 database).

Chạy test

uv run python -m pytest                          # toan bo suite
uv run python -m pytest tests/common/test_ids.py  # 1 file
uv run python -m pytest tests/common/test_ids.py::test_uuid7_returns_valid_uuid   # 1 test

Fixture: dữ liệu/setup dùng chung giữa nhiều test

# tests/conftest.py — pytest tu dong nap file nay
import pytest

@pytest.fixture
def sample_book():
    return Book.objects.create(title="Chi Pheo", author="Nam Cao")

# trong file test khac:
def test_book_is_available_by_default(sample_book):
    assert sample_book.available is True

Đặt tên tham số của hàm test trùng tên fixture — pytest tự "tiêm" giá trị fixture vào, không cần import hay gọi tay.
