JWT & actor_type — Cheat Sheet

Claim thêm vào token khi tạo

refresh = RefreshToken.for_user(customer)
refresh["actor_type"] = "customer"
refresh.access_token["actor_type"] = "staff"   # hoac "customer" tuy actor

for_user() chỉ cần object có id — không cần AUTH_USER_MODEL.

Override get_user() để dispatch theo claim

class JWTAuthentication(BaseJWTAuthentication):
    def get_user(self, validated_token):
        actor_type = validated_token.get("actor_type")
        actor_id = validated_token.get("user_id")
        if actor_type == "customer":
            return Customer.objects.get(id=actor_id, is_active=True)
        if actor_type == "staff":
            return Staff.objects.get(id=actor_id, is_active=True)
        raise InvalidToken("...")

Không khớp claim nào → InvalidToken, không có nhánh "mặc định".

Shim bắt buộc khi model không kế thừa AbstractBaseUser

class Customer(BaseModel):
    @property
    def is_authenticated(self):
        return True

    @property
    def is_anonymous(self):
        return False

Thiếu 2 property này, IsAuthenticated của DRF báo AttributeError dù JWT hợp lệ.

Token khác thời hạn bằng subclass, không bằng if

class StaffAccessToken(AccessToken):
    lifetime = timedelta(minutes=10)

class StaffRefreshToken(RefreshToken):
    lifetime = timedelta(days=7)
    access_token_class = StaffAccessToken

refresh = StaffRefreshToken.for_user(staff)

SIMPLE_JWT setting chỉ áp dụng cho token mặc định (Customer); Staff dùng class riêng để override lifetime.
