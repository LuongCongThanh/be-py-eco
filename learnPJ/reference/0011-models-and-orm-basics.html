Model & ORM cơ bản — Cheat Sheet

Model = 1 class Python = 1 table trong database

from django.db import models

class Book(models.Model):
    title = models.CharField(max_length=200)
    author = models.CharField(max_length=200)
    available = models.BooleanField(default=True)
    created_at = models.DateTimeField(auto_now_add=True)

Mỗi thuộc tính là một cột. models.Model là base class cung cấp toàn bộ hành vi ORM (lưu, truy vấn, ...).

Migration: đồng bộ class Python ↔ schema database

uv run python manage.py makemigrations   # sinh file migration tu thay doi model
uv run python manage.py migrate           # ap dung migration vao database

makemigrations so sánh model hiện tại với migration cũ, sinh ra file Python mô tả thay đổi. migrate chạy các file đó để thực sự sửa schema trong Postgres.

QuerySet: truy vấn qua method chain, không viết SQL tay

Book.objects.all()
Book.objects.filter(available=True)
Book.objects.filter(author="Nam Cao").first()
Book.objects.get(id=some_id)          # loi neu khong tim thay hoac tim thay > 1
Book.objects.create(title="Chi Pheo", author="Nam Cao")

Book.objects là một manager — điểm vào để xây QuerySet. Mỗi .filter()/.exclude() trả về một QuerySet mới, có thể chain tiếp.

Lazy evaluation: QuerySet chưa chạy SQL cho tới khi cần

qs = Book.objects.filter(available=True)   # CHUA chay SQL
for book in qs:                             # bay gio moi chay SQL
    print(book.title)
