Class cơ bản trong Python — Cheat Sheet

Định nghĩa class

class Dog:
    def __init__(self, name, breed):
        self.name = name
        self.breed = breed

    def bark(self):
        return f"{self.name} says woof!"

Khởi tạo object — không có new

rex = Dog("Rex", "Labrador")
print(rex.bark())   # "Rex says woof!"

Gọi tên class như một hàm sẽ tạo object mới và tự động gọi __init__. Không có từ khóa new.

self: tham số đầu tiên, luôn tường minh

self là chính object đang được thao tác — tương đương this ở ngôn ngữ khác, nhưng ở Python nó là một tham số bình thường, phải khai báo tường minh trong mọi method, và Python tự động truyền nó vào khi bạn gọi rex.bark().

__init__: hàm khởi tạo

Chạy tự động khi tạo object, dùng để gán các thuộc tính ban đầu (self.name = name). Tên có 2 dấu gạch dưới ở đầu và cuối — đây là một "dunder method" (double underscore), Python dùng quy ước này cho các hook đặc biệt.

Thuộc tính (attributes) & phương thức (methods)

rex.name          # "Rex" — truy cập thuộc tính
rex.bark()        # gọi method

Kế thừa (inheritance)

class Puppy(Dog):
    def bark(self):
        return f"{self.name} says yip!"  # ghi đè (override)
