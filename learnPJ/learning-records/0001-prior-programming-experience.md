# Đã biết lập trình, chưa từng dùng Python

Bạn đã biết lập trình bằng một ngôn ngữ khác (biến, hàm, control flow, OOP)
nhưng chưa từng viết Python. Các bài học nên trình bày mỗi khái niệm Python
theo hướng "khác gì so với cái bạn đã biết" — đặc biệt là block dựa trên
thụt lề, kiểu dữ liệu động (dynamic typing), và các cấu trúc dữ liệu
built-in của Python (list/dict/tuple/set) cùng các idiom đi kèm
(comprehension, unpacking, `for...in`, slicing).
