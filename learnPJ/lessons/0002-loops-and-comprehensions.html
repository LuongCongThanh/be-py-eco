Vòng lặp Pythonic: không đếm chỉ số, lặp thẳng trên phần tử

Python tách bạch hai việc mà C/Java gộp vào một vòng lặp: "duyệt qua phần tử" và "đếm số". Từ đó có range(), enumerate() và list comprehension — thay vì một cú pháp for vạn năng.

1. for luôn là "for-each" — vì sao?

Cái bạn quen dùng

for (int i = 0; i < n; i++) {
  print(items[i]);
}

Python

fruits = ["apple", "banana", "cherry"]
for item in fruits:
    print(item)
# -> apple
# -> banana
# -> cherry

Python không có for kiểu C. for luôn lặp trực tiếp trên phần tử của một iterable (list, tuple, string, dict, file...) — không chỉ số, không lỗi off-by-one.

2. Cần đếm số? Dùng range()

for i in range(5):     # 0, 1, 2, 3, 4
    print(i)
# -> 0
# -> 1
# -> 2
# -> 3
# -> 4

range() không tạo sẵn list trong bộ nhớ — nó lazy, chỉ giữ 3 số (start, stop, step) và sinh giá trị khi cần. Vì vậy range(10**9) không tốn RAM.

print(range(5))          # range(0, 5) — không phải [0, 1, 2, 3, 4]
print(list(range(5)))   # [0, 1, 2, 3, 4] — ép về list mới thấy hết giá trị

3. Cần cả chỉ số lẫn giá trị? Dùng enumerate()

fruits = ["apple", "banana", "cherry"]
for i, fruit in enumerate(fruits):
    print(i, fruit)
# -> 0 apple
# -> 1 banana
# -> 2 cherry
Đây là một ví dụ của unpacking: enumerate() trả về từng cặp (chỉ_số, giá_trị), và Python tự động "tách" cặp đó thành hai biến i, fruit cùng lúc — không cần viết pair[0], pair[1].

for i in range(len(fruits)): fruit = fruits[i] chạy đúng nhưng là anti-pattern — quay lại quản lý chỉ số thủ công. enumerate() tránh được điều đó.

4. while — không có gì bất ngờ

n = 5
while n > 0:
    print(n)
    n -= 1    # Python không có n-- hay n++
# -> 5
# -> 4
# -> 3
# -> 2
# -> 1

Giống hệt ngôn ngữ khác, chỉ khác: Python không có ++/--, phải viết n -= 1.

5. List comprehension: viết vòng lặp tạo list trong 1 dòng

squares = [x * x for x in range(5)]
print(squares)
# -> [0, 1, 4, 9, 16]

evens = [x for x in range(10) if x % 2 == 0]
print(evens)
# -> [0, 2, 4, 6, 8]

Gói 3 bước (tạo list rỗng, for, append) thành một biểu thức. Đọc là: "với mỗi x trong range(10), nếu chẵn, lấy x".

# Cách viết dài (3 bước)
evens = []
for x in range(10):
    if x % 2 == 0:
        evens.append(x)

# Cách viết comprehension (1 dòng, cùng kết quả)
evens = [x for x in range(10) if x % 2 == 0]

Comprehension là idiom chuẩn cho "lọc/biến đổi iterable A thành list B" — đọc lướt là hiểu ngay ý đồ.

6. Trường hợp dễ nhầm: comprehension tạo list mới, không sửa list cũ

numbers = [1, 2, 3]
doubled = [n * 2 for n in numbers]
print(numbers)   # -> [1, 2, 3]   (không đổi!)
print(doubled)   # -> [2, 4, 6]   (list hoàn toàn mới)

[... for ... in ...] luôn tạo giá trị mới, không sửa list gốc. Muốn sửa tại chỗ, dùng vòng lặp for thường:

numbers = [1, 2, 3]
for i in range(len(numbers)):
    numbers[i] = numbers[i] * 2
print(numbers)   # -> [2, 4, 6]   (lần này list gốc đổi thật)

7. Dict comprehension: cùng ý tưởng, áp dụng cho dict

names = ["an", "binh", "chi"]
lengths = {name: len(name) for name in names}
print(lengths)
# -> {'an': 2, 'binh': 4, 'chi': 3}

Giống hệt list comprehension, chỉ đổi [] thành {} và viết key: value.
