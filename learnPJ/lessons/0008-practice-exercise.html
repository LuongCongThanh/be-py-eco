Thực hành: viết một "Thư viện mini" bằng Python

Đây không phải bài học mới — là bài tập bắt bạn tự viết code, dùng lại cả 7 khái niệm từ bài 1–7. Đọc yêu cầu, tự viết trong một file .py, chạy bằng uv run python ten_file.py (xem how-to-run.md nếu quên cách chạy), rồi quay lại làm phần "dự đoán kết quả" bên dưới để tự kiểm tra hiểu đúng chưa.

Đề bài

Viết một chương trình quản lý thư viện nhỏ, gồm:

  1. (Bài 4 — class) Một class Book với __init__(self, title, author, available=True) và một method info(self) trả về chuỗi f"{self.title} by {self.author}".
  2. (Bài 5 — dict) Một dict tên library, key là tiêu đề sách (str), value là object Book tương ứng. Thêm ít nhất 3 quyển sách.
  3. (Bài 3 — function trả tuple) Một hàm checkout(library, title): nếu sách tồn tại và available == True, đặt available = False và trả về (True, "checked out"); nếu không tồn tại, trả về (False, "not found"); nếu đã có người mượn, trả về (False, "already out").
  4. (Bài 6 — exception) Khi gọi checkout với tiêu đề không tồn tại, thay vì trả tuple lỗi, hãy đổi hàm để raise ValueError — rồi bọc lời gọi hàm bằng try/except ValueError ở nơi gọi, in ra thông báo lỗi thay vì để chương trình crash.
  5. (Bài 2 — comprehension) Một dòng list comprehension lấy ra danh sách tiêu đề của tất cả sách còn available == True trong library.
  6. (Bài 7 — decorator) Viết một decorator @log_call (giống bài 7) và gắn nó lên hàm checkout, để mỗi lần checkout đều in ra "goi checkout" trước khi thực hiện.
Không cần dùng with/context manager trong bài này (không có file thật để mở) — nếu muốn thử thêm, có thể ghi log ra một file bằng with open("log.txt", "a") as f: f.write(...) bên trong decorator, thay vì print.

Không có "đáp án mẫu" đính kèm ở đây — hãy tự viết, tự chạy thử, rồi hỏi Claude để review code của bạn khi xong. Đó là cách luyện tập thật (retrieval practice) thay vì đọc code có sẵn.

Dự đoán kết quả (làm sau khi đã tự viết xong)

Ba câu dưới đây kiểm tra bạn có dự đoán đúng hành vi Python trong chính bài tập trên không — không nhìn code mẫu, tự suy luận từ những gì đã học ở bài 1–7.

1. Gọi checkout(library, "Ten sach khong ton tai") sau khi bạn đã đổi hàm sang dùng raise — nếu KHÔNG bọc trong try/except, điều gì xảy ra?

2. [title for title, book in library.items() if book.available] — cấu trúc for title, book in ... ở đây là gì?

3. Sau khi gắn @log_call lên checkout, gọi checkout(library, "A") tương đương viết lại thành gì?

Viết xong code — dán vào chat và nhờ Claude review giúp, hoặc hỏi bất cứ chỗ nào bị mắc kẹt. Đây chính là lúc câu hỏi của bạn có giá trị nhất, vì nó đến từ việc tự tay viết code thật.
