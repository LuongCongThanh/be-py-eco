Bài 1 · Python cốt lõi

Python đọc khác gì so với những gì bạn đã biết

Bạn đã biết lập trình rồi. Bài này chỉ nêu những điểm khác biệt cụ thể giữa Python và các ngôn ngữ khác.

1. Block dựa trên thụt lề, không dùng dấu ngoặc

Không có { }, không có end. Dấu hai chấm mở một block; các dòng cùng mức thụt lề bên dưới thuộc block đó — thụt lề chính là cú pháp, không phải style.

Cái bạn quen dùng

if (x > 0) {
  print("positive");
}

Python

if x > 0:
    print("positive")
Thụt lề sai (trộn tab/space, hoặc thụt lề không nhất quán) sẽ khiến Python báo IndentationError — ở đây nó không chỉ là style, mà là cú pháp bắt buộc. 
x = 5
if x > 0:
    print("duong")
    print("van la duong")   # -> in ca 2 dong, vi cung thuoc block if

x = -1
if x > 0:
    print("duong")
print("van la duong")       # -> luon in, vi khong con thut le vao if nua

Quy ước phổ biến là thụt lề 4 space, không trộn với tab.

2. Biến không khai báo kiểu

x = 5        # x tro toi mot int
x = "five"   # gio x tro toi mot str -- hoan toan hop le, khong loi
print(x)     # -> five

Mỗi giá trị có một kiểu. Tên biến chỉ là nhãn có thể trỏ tới bất kỳ giá trị nào, bất cứ lúc nào. Đây gọi là dynamic typing.

Python vẫn kiểm tra kiểu, chỉ là kiểm tra lúc chạy (runtime) chứ không phải lúc biên dịch.

x = "five"
y = x + 1   # -> TypeError: can only concatenate str (not "int") to str

3. Các kiểu built-in bạn sẽ gặp liên tục

int, float, str, bool (True/False), và None (giống null/nil trong ngôn ngữ khác). Cộng thêm 4 container built-in bạn sẽ dùng thay vì tự viết: list ([1, 2, 3], có thứ tự & mutable), tuple ((1, 2, 3), có thứ tự & immutable), dict ({"a": 1}, key→value), và set ({1, 2, 3}, duy nhất & không thứ tự).

nums = [1, 2, 3]
nums.append(4)      # -> [1, 2, 3, 4], list mutable nen sua duoc

point = (10, 20)
point.append(30)     # -> AttributeError: 'tuple' object has no attribute 'append'

tuple immutable là tín hiệu "dữ liệu này không đổi sau khi tạo", ví dụ toạ độ (x, y).

4. Format chuỗi: f-string

name = "world"
print(f"hello, {name}!")   # -> hello, world!

age = 25
print(f"nam sau se {age + 1} tuoi")   # -> nam sau se 26 tuoi

f"..." tính giá trị bất kỳ biểu thức nào trong {...} rồi chèn vào chuỗi, như age + 1 ở trên.

5. Vì sao không có dấu chấm phẩy, không có khai báo kiểu?

Xuống dòng và thụt lề đã làm nhiệm vụ đánh dấu ranh giới lệnh/block, nên dấu chấm phẩy và khai báo kiểu tường minh trở thành thừa.
